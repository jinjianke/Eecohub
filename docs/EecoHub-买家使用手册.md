# EecoHub 买家使用手册

> 适用于购买 EecoHub 静态网站部署卡密的用户  
> 更新日期：2026年7月29日  
> 使用入口：[https://eecohub.top](https://eecohub.top)

---

## 一、EecoHub 是什么

EecoHub 是一个静态网站在线发布平台。

你只需要输入卖家发放的卡密，上传 HTML 文件或 ZIP 网站压缩包，系统就会自动发布网站，并生成一个可在电脑和手机浏览器中访问的 HTTPS 公网网址。

你不需要自行购买服务器，也不需要配置 Nginx、域名或 HTTPS 证书。

### 支持的内容

- 单个 `.html` 或 `.htm` 网页；
- 包含 HTML、CSS、JavaScript 的完整 ZIP 网站；
- 图片、字体、音频等静态资源；
- HTML/CSS/JS 课程作业；
- 个人主页、简历、作品集；
- 活动页、产品展示页；
- 已完成构建的 Vue、React、Vite 静态项目。

### 不支持的内容

- PHP、Python、Java、Node.js 等服务端程序；
- MySQL、SQLite、Redis 等服务器数据库；
- 需要在服务器安装依赖或运行命令的项目；
- 登录注册、支付、订单、服务器存储等后端功能；
- `.exe`、`.bat`、`.cmd`、`.sh`、`.ps1` 等程序或脚本；
- 违法、诈骗、钓鱼、侵权或恶意内容。

## 二、使用前准备

请提前准备：

1. 卖家发送给你的完整卡密；
2. 需要发布的 HTML 文件或 ZIP 网站文件；
3. Chrome、Edge、Safari、Firefox 等现代浏览器；
4. 稳定的网络连接。

卡密格式通常类似：

```text
EH-XXXX-XXXX-XXXX
```

请勿公开卡密。其他人获得卡密后，可能覆盖你已经发布的网站。

## 三、第一次发布网站

### 第1步：打开平台

在浏览器中访问：

[https://eecohub.top](https://eecohub.top)

请确认浏览器地址栏中的域名为 `eecohub.top`。

如果咸鱼、微信等软件的内置浏览器无法选择文件，请选择“在浏览器中打开”，然后使用 Chrome、Edge 或 Safari。

### 第2步：验证卡密

1. 找到卡密输入框；
2. 粘贴卖家发送的完整卡密；
3. 点击 **“验证并继续”**；
4. 验证成功后进入上传页面。

如果验证失败，请检查：

- 卡密是否完整；
- 卡密前后是否带有空格或换行；
- 是否误把订单号或买家 ID 当成卡密；
- 字母和数字是否输入错误；
- 卡密是否已经到期或停用。

### 第3步：选择文件

支持上传：

```text
.html
.htm
.zip
```

你可以点击上传区域选择文件，也可以在电脑上把文件拖入上传区域。

选择后，请检查页面显示的文件名和大小，确认没有选错版本。

### 第4步：发布到云端

1. 点击 **“发布到云端”**；
2. 等待系统检查并上传文件；
3. 发布过程中不要刷新或关闭页面；
4. 一般需要约 10～60 秒；
5. 出现“网站发布成功”即表示部署完成。

网络较慢或文件较多时，可能需要更长时间。请勿连续重复点击发布按钮。

### 第5步：保存网址

发布成功页面会显示：

- 网站公网网址；
- 上传的文件数量；
- 累计发布次数；
- 卡密到期日期。

点击 **“复制”** 保存网址，或者点击 **“打开网站”** 查看效果。

生成的网址一般类似：

```text
https://eeco-xxxxxxxx.rth1.xyz
```

请以发布成功页面显示的网址为准。

## 四、如何上传单个 HTML 文件

如果网页所有内容都写在一个 HTML 文件中，可以直接上传该文件，不需要压缩。

### 文件要求

- 扩展名为 `.html` 或 `.htm`；
- 文件大小不超过 10MB；
- 文件内容不能为空；
- 建议使用 UTF-8 编码保存。

适合直接上传单个 HTML 的情况：

- CSS 写在 `<style>` 标签中；
- JavaScript 写在 `<script>` 标签中；
- 没有需要同时上传的本地图片、CSS 或 JS 文件。

如果 HTML 引用了本地文件，例如：

```html
<link rel="stylesheet" href="css/style.css">
<script src="js/main.js"></script>
<img src="images/logo.png" alt="Logo">
```

请将 HTML、CSS、JS 和图片一起制作成 ZIP 后上传。

## 五、如何制作 ZIP 网站文件

### 推荐目录结构

```text
index.html
css/
  style.css
js/
  main.js
images/
  logo.png
  banner.jpg
pages/
  about.html
```

网站入口文件必须为：

```text
index.html
```

### Windows 压缩方法

1. 打开网站文件夹；
2. 选中 `index.html`、CSS、JS、图片等全部网站文件；
3. 单击右键；
4. 选择“压缩到 ZIP 文件”或“发送到 → 压缩文件夹”；
5. 打开生成的 ZIP；
6. 确认 ZIP 中能够看到 `index.html`；
7. 上传该 ZIP。

### macOS 压缩方法

1. 打开网站文件夹；
2. 选中网站所需的全部文件；
3. 单击右键并选择“压缩”；
4. 检查 ZIP 中是否包含 `index.html`；
5. 上传生成的 ZIP。

### 正确结构

推荐：

```text
index.html
css/style.css
js/main.js
images/logo.png
```

只有一个外层文件夹通常也可以识别：

```text
my-website/index.html
my-website/css/style.css
my-website/js/main.js
```

但应避免多层无关目录：

```text
最终版/新建文件夹/网页作业/完成版/index.html
```

### 不要放入 ZIP 的内容

通常不需要上传：

```text
node_modules/
.git/
.vscode/
.idea/
PSD设计源文件
项目备份
其他ZIP、RAR、7Z压缩包
数据库文件
无关的大型视频
```

## 六、文件限制

| 检查项目 | 当前限制 |
|---|---:|
| 上传的 HTML 或 ZIP | 最大 20MB |
| ZIP 解压后的总大小 | 最大 50MB |
| ZIP 内文件数量 | 最多 1000 个 |
| 单个文件大小 | 最大 10MB |
| 网站入口文件 | `index.html` |

如果文件过大，可以：

- 压缩 PNG、JPG、WebP 图片；
- 删除未使用的图片和字体；
- 删除 `node_modules`；
- 删除项目备份和设计源文件；
- 不要把大型视频直接放进网站；
- 删除 ZIP 中的其他压缩包。

## 七、网页资源路径规范

网站发布到云端后，无法读取你电脑里的本地路径。

### 正确：使用相对路径

```html
<link rel="stylesheet" href="css/style.css">
<script src="js/main.js"></script>
<img src="images/logo.png" alt="Logo">
<a href="pages/about.html">关于页面</a>
```

也可以写成：

```html
<img src="./images/logo.png" alt="Logo">
```

### 错误：使用电脑本地路径

```html
<img src="C:\Users\Admin\Desktop\logo.png">
<link rel="stylesheet" href="D:\Project\style.css">
```

以下地址也不能供其他人访问：

```text
file:///C:/Users/Admin/Desktop/index.html
http://localhost:3000
```

### 文件名大小写必须一致

云端通常严格区分大小写：

```text
logo.png
Logo.png
LOGO.PNG
```

可能会被识别为不同文件。

如果真实文件名是：

```text
images/Logo.png
```

HTML 中也必须写为：

```html
<img src="images/Logo.png" alt="Logo">
```

建议使用小写英文、数字、短横线或下划线命名文件，例如：

```text
index.html
about-us.html
main.js
style.css
banner-01.jpg
```

## 八、Vue、React、Vite 项目上传方法

EecoHub 不能直接运行需要 `npm run dev` 的源代码项目，但可以发布构建完成的静态文件。

### Vite 或 Vue 项目

一般在项目目录运行：

```bash
npm install
npm run build
```

构建成功后通常会生成：

```text
dist/
```

确认其中包含：

```text
dist/index.html
dist/assets/...
```

然后打开 `dist` 文件夹，将里面的全部内容压缩为 ZIP，再上传到 EecoHub。

### React 项目

构建结果通常位于：

```text
dist/
```

或：

```text
build/
```

请上传构建输出目录中的内容，不要上传带有 `node_modules` 的完整开发项目。

### 前端路由注意事项

如果网站使用 Vue Router 或 React Router：

- Hash 路由通常更适合静态网站；
- History 路由直接打开或刷新子页面时可能出现 404；
- 如果刷新子页面出现 404，可改用 Hash 路由后重新构建。

Hash 路由网址一般类似：

```text
https://你的网站网址/#/about
```

## 九、如何更新已经发布的网站

同一张卡密可以覆盖更新已经绑定的网站。

### 更新步骤

1. 打开 [https://eecohub.top](https://eecohub.top)；
2. 输入第一次发布时使用的同一卡密；
3. 验证成功后查看当前网站网址；
4. 选择新的完整 HTML 或 ZIP；
5. 点击 **“发布到云端”**；
6. 等待发布成功；
7. 打开原网址检查新内容。

### 更新规则

- 更新后原网址保持不变；
- 新内容会覆盖旧内容；
- 累计发布次数会增加；
- 重新上传不会重新计算 365 天有效期；
- 每次更新都应上传一个完整的网站文件，而不是只上传一张图片或一个 CSS 文件。

### 更新后仍显示旧内容

可能是浏览器缓存，可以尝试：

- Windows：按 `Ctrl + F5`；
- macOS：按 `Command + Shift + R`；
- 手机：关闭网页后重新打开；
- 使用无痕模式访问；
- 清除浏览器缓存；
- 等待几十秒后重新访问。

也可以临时在网址后添加参数：

```text
https://你的网站网址/?v=2
```

## 十、卡密使用规则

### 首次激活

- 输入并验证新卡密不会立即开始计时；
- 卡密在第一次成功发布网站后激活；
- 首次发布失败通常不会开始计算有效期；
- 首次成功发布后，卡密会绑定一个网站网址。

### 有效期

- 卡密首次成功发布后有效期为 365 天；
- 页面会显示具体到期日期；
- 重新上传不会重置有效期；
- 卡密到期后不能继续发布或更新；
- 如需继续使用，请联系卖家咨询续期。

### 安全保存

- 一张卡密对应一个网站；
- 公开分享网址即可，不要公开分享卡密；
- 获得卡密的人可能能够覆盖网站内容；
- 建议同时保存订单号、买家 ID、卡密、网址和到期日期。

建议使用以下格式记录：

```text
订单号：
买家 ID：
EecoHub 卡密：
网站网址：
首次发布日期：
到期日期：
```

## 十一、安全检查说明

平台会检查上传内容，以防止钓鱼、诈骗和恶意程序。

下列内容可能被拦截：

- 收集密码的输入框；
- 自动跳转代码；
- 自动弹窗；
- `iframe` 嵌入其他网页；
- 向外部网站提交表单；
- `window.location` 跳转；
- `location.assign()` 或 `location.replace()`；
- `window.open()`；
- `javascript:` 链接；
- 后端程序和可执行文件；
- ZIP 中嵌套其他压缩包。

请勿尝试绕过安全检查。如果正规项目确实需要相关功能，请先联系卖家说明用途。

## 十二、常见错误处理

### 1. 卡密不正确

检查卡密是否完整、是否有空格、是否误输入订单号。仍无法使用时，请私聊卖家并提供订单信息和错误截图。

### 2. 卡密已停用

使用购买商品的账号联系卖家核实。不要在公开评论区发送完整卡密。

### 3. 卡密已过期

联系卖家咨询续期。续期前请提供原订单和网站网址。

### 4. 请选择 HTML 或 ZIP 文件

平台只接受：

```text
.html
.htm
.zip
```

RAR、7Z 或文件夹不能直接上传。

### 5. 文件超过 20MB

压缩图片、删除无用文件、删除 `node_modules` 和嵌套压缩包后重新上传。

### 6. 网站根目录必须包含 index.html

打开 ZIP，确认入口文件名是：

```text
index.html
```

不要使用：

```text
首页.html
home.html
index.html.txt
```

### 7. ZIP 文件无法读取

请先在电脑上解压检查，再用系统自带压缩功能重新制作 ZIP。不要直接把 `.rar` 后缀改成 `.zip`。

### 8. 不支持某种文件类型

根据提示删除 ZIP 中的后端文件、可执行文件、脚本或嵌套压缩包，然后重新压缩上传。

### 9. 发布成功但页面空白

检查：

1. `index.html` 是否有内容；
2. 是否上传了构建结果而不是项目源代码；
3. CSS、JS 和图片路径是否正确；
4. 文件名大小写是否一致；
5. JavaScript 是否依赖本地开发服务器；
6. 浏览器开发者工具 Console 中是否有报错。

### 10. CSS 没有生效

确认 HTML 中的路径与 ZIP 中的位置完全一致：

```html
<link rel="stylesheet" href="css/style.css">
```

对应文件应为：

```text
css/style.css
```

### 11. 图片不显示

检查图片是否放入 ZIP、路径是否为相对路径、文件名和扩展名是否一致，以及是否错误使用了 `C:\`、`D:\` 或 `file:///` 地址。

### 12. JavaScript 失效

可能原因：

- JS 路径错误；
- 代码依赖 Node.js；
- 代码依赖本地开发服务器；
- 第三方 API 不允许跨域；
- HTTPS 页面请求了 HTTP 接口；
- 项目构建时资源路径设置错误。

### 13. 第三方 API 无法访问

第三方接口必须支持 HTTPS，并允许浏览器跨域访问。CORS 是否开放由第三方接口决定。

不要在前端 HTML 或 JS 中保存私密 API Key、数据库密码或服务器密钥。访问者可以查看前端源代码。

### 14. 打开子页面出现 404

检查目标 HTML 文件是否存在、路径和大小写是否正确。如果是 Vue 或 React 单页应用，可改用 Hash 路由。

### 15. 一直显示正在发布

1. 等待 1～3 分钟；
2. 不要重复点击按钮；
3. 检查网络连接；
4. 刷新平台并重新输入同一卡密；
5. 重新上传完整文件；
6. 仍失败时，将错误截图和发生时间发送给卖家。

### 16. 自己能打开，别人打不开

确认分享的是以 `https://` 开头的公网网址，而不是：

```text
localhost
127.0.0.1
file:///
```

同时检查复制网址时是否遗漏字符，并让对方更换浏览器或网络测试。

## 十四、发布前检查清单

上传前请逐项确认：

- [ ] 项目是纯静态网站；
- [ ] 网站入口文件为 `index.html`；
- [ ] HTML、CSS、JS 和图片使用相对路径；
- [ ] 文件名大小写完全一致；
- [ ] 没有使用 `C:\`、`D:\`、`file:///` 或 `localhost`；
- [ ] 没有把 `node_modules` 放入 ZIP；
- [ ] 没有 PHP、Python、EXE 等不支持的文件；
- [ ] ZIP 中没有其他 ZIP、RAR 或 7Z；
- [ ] 上传文件不超过 20MB；
- [ ] ZIP 解压后不超过 50MB；
- [ ] 文件总数不超过 1000 个；
- [ ] 单个文件不超过 10MB；
- [ ] 没有密码收集、恶意跳转或自动弹窗；
- [ ] 已在本地检查网页基本效果；
- [ ] 已保存项目源文件和备份；
- [ ] 已妥善保存卡密和订单信息。
